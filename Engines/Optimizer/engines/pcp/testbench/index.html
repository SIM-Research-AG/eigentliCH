Mandate

The client's mandate as JSON (pcp-mandate@1.0.0). Economy weights blend the client's Regime; a market name uses aggregation's published blend. The Currency select sets the mandate's reporting currency: fmre measures the profiles in it, the target curve is read in it, and the ReturnSet id is the one fmre serves for it (PCP-18). The Basis select sets the basis of the target curve, nominal by default or real (net of the currency's inflation per state); fmre serves the profiles on it and the ReturnSet id is the one for that basis (PCP-22).
